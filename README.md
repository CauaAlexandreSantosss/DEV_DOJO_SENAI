# 🎮 Sistema de Gerenciamento de Loja de Games

Projeto desenvolvido como parte de um **desafio em grupo do SENAI**, com o objetivo de aplicar os conhecimentos iniciais da linguagem **C#** e os fundamentos de lógica de programação.

## 📌 Sobre o projeto

O sistema simula o gerenciamento de uma loja de games, permitindo cadastrar informações de clientes, consultar jogos, gerenciar uma biblioteca pessoal e gerar relatórios de compras e horas jogadas.

Durante o desenvolvimento, foram aplicados conceitos fundamentais de programação para resolver problemas e implementar regras de negócio.

## ⚙️ Funcionalidades

- **Cadastro de clientes:** registro de nome, nickname, plataforma, ano de cadastro e saldo disponível.
- **Consulta de jogos:** verificação de compatibilidade entre plataformas e saldo para compra.
- **Biblioteca de jogos:** armazenamento e listagem dos jogos cadastrados.
- **Busca de jogos:** identificação de jogos já existentes na biblioteca.
- **Relatório financeiro:** cálculo do total gasto, média por compra e identificação de cliente VIP.
- **Controle de horas jogadas:** registro de horas, identificação do jogo mais jogado e jogos não utilizados.
- **Compra de jogos:** validação de saldo, plataforma e compras duplicadas.
- **Ranking Top 3:** identificação dos três jogos com maior quantidade de horas jogadas.
- **Menu interativo:** navegação entre as funcionalidades do sistema.

## 🧠 Conceitos aplicados

Durante o desafio, foram trabalhados os seguintes fundamentos:

- Variáveis e tipos de dados.
- Entrada e saída de informações (`Console.ReadLine` e `Console.WriteLine`).
- Estruturas condicionais (`if`, `else if` e `else`).
- Estruturas de repetição (`for`, `while` e `do while`).
- Arrays e manipulação de coleções.
- Operadores lógicos e relacionais.
- Métodos de comparação de strings.
- Cálculos matemáticos e operações com valores monetários.
- Manipulação dinâmica de arrays com `Array.Resize`.
- Estrutura de seleção `switch`.
- Validação de dados e implementação de regras de negócio.

## 🛠️ Tecnologias

- **Linguagem:** C#
- **Plataforma:** .NET
- **Ambiente:** Aplicação de console.

## 🎯 Objetivo de aprendizagem

O principal objetivo foi consolidar os fundamentos de C# e desenvolver o raciocínio lógico por meio da resolução progressiva de desafios.

O projeto também proporcionou contato com situações que simulam regras de negócio presentes em sistemas reais, incentivando a organização das informações, a validação de dados e a construção de soluções.
